回填规则

  • 已有合法 Parquet 字段 ID 的列保持不动；缺 ID 的列按 name-mapping 的名称/别名唯一匹配。
  • struct 子列先用父字段的 ID 在映射树中找到对应子节点，再在该作用域内匹配，同名子列不会串到别的 struct。
  • 只处理标量列和一层 struct；list / map / 嵌套 struct 会报错并指出文件与列路径。
  • 分批逐行组重写：列名、类型、可空性、值与行序不变，行组边界、每列压缩、列统计与 schema 级元数据保留。
  • 原清单和位置删除文件继续使用；全部成功后按原上传文件名打包 ZIP 返回。
  • 缺文件、列无法唯一匹配、单文件内 ID 重复或读写失败：指出问题文件和涉及列，整批中止、不提供下载。

字段 ID 写入 Parquet 模式的 PARQUET:field_id，查询引擎据此按 ID 读取票价列。上传文件只保存在一次请求的临时目录中，请求结束后删除。
