处理规则

  • 已有 ID 不动：列上已有 PARQUET:field_id 时原样保留。
  • 缺 ID 唯一匹配：按列名与 name mapping 的别名匹配，必须恰好命中一个条目。
  • 子列走父 ID：struct 子列只在父字段 ID 指向的映射分支里查找，所以不同 struct 下的同名子列会得到不同 ID。
  • 单文件内唯一：同一文件中已有 ID 与新补 ID 不得重复，重复即报错。
  • 全有或全无：缺文件、列无法唯一匹配、ID 重复或读写失败都会指出文件与涉及的列，本次不提供下载。
  • 只处理 data：位置删除文件和原清单继续使用；成功后按原上传文件名打包 ZIP。

补齐的是 Parquet 模式里的 Iceberg 字段 ID，使查询引擎可以按 ID 读到票价； 列名、类型、值与行序保持原样，原有 ID 不覆盖，原清单与位置删除文件继续使用。
